//1A
state 0: 1이 현재 3n개 있는 상태. 입력을 읽고 공백으로 바꿈. 입력이 공백이면 accept로 이동, 1이면 1로 이동, 그 외이면 reject로 이동.
state 1: 1이 현재 3n+1개 있는 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이면 2로 이동, 그 외이면 reject로 이동.
state 2: 1이 현재 3n+2개 있는 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이면 0으로 이동, 그 외이면 reject로 이동.
state accept: 1을 출력하고 halt
state reject: 남아있는 입력을 전부 공백으로 바꿈. 0을 출력하고 halt
//1B
state0: 짝수번 째 자리를 읽는 상태. 입력을 읽고 공백으로 바꿈. 입력이 0이면 1로 이동, 1이면 reject로 이동. 공백이면 accept로 이동. (nonempty input만 입력되므로 예외처리 필요X)
state1: 홀수번 째 자리를 읽는 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이면 0으로 이동, 그 외엔 reject로 이동.
state accept: 1을 출력하고 halt
state reject: 남아있는 입력을 전부 공백으로 바꿈. 0을 출력하고 halt
//1C
state 0: 4n+1번 째 자리를 읽는 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이면 1o로 이동, 그 외엔 1e로 이동. 공백이면 accept로 이동. (nonempty input만 입력되므로 예외처리 필요X)
state 1e: 4n+2번 째 자리, 1이 짝수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 공백이면 reject로 이동. 1이면 2o로 이동. 그 외엔 2e로 이동.
state 1o: 4n+2번 째 자리, 1이 홀수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 공백이면 reject로 이동. 1이면 2e로 이동. 그 외엔 2o로 이동.
state 2e: 4n+3번 째 자리, 1이 짝수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 공백이면 reject로 이동. 1이면 3o로 이동. 그 외엔 3e로 이동.
state 2o: 4n+3번 째 자리, 1이 홀수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 공백이면 reject로 이동. 1이면 3e로 이동. 그 외엔 3o로 이동.
state 3e: 4n번 째 자리, 1이 짝수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이면 0으로 이동, 그 외엔 reject로 이동.
state 3o: 4n번 째 자리, 1이 홀수개인 상태. 입력을 읽고 공백으로 바꿈. 입력이 1이나 공백이면 reject로 이동. 그 외엔 0으로 이동.
state accept: 1을 출력하고 halt
state reject: 남아있는 입력을 전부 공백으로 바꿈. 0을 출력하고 halt
//1D
state0: 입력에서 첫 0이 나올 때까지 머무는 상태. 출력에서 선행 0은 전부 지워야하므로 입력에 1이 들어오면 공백으로 바꾸고 상태 유지. 입력이 0이면 1 출력하고 state1로 이동. 입력이 공백이면 halt.
state1: 입력의 trailing 1이 전부 지워진 상태. 입력을 받고 0이면 1출력, 1이면 0 출력 후 상태 유지. 입력이 공백이면 halt.
//1E
설명의 편의를 위해 input의 형식을 다음과 같이 정의: "a1a2_b1b2" (올바른 형태의 input만 들어옴)
state 0에서 a1을 읽고 공백으로 바꿈. a1==0이면 0read2nd로 이동, a1==1이면 1read2nd로 이동.
state 0read2nd에서 a2를 읽고 공백으로 바꿈. a2==0이면 r로 이동, a2==1이면 p로 이동.
state 1read2nd에서 a2를 읽고 공백으로 바꿈. a2는 무조건 0, s로 이동.
state r에서 일단 공백을 읽고 무시. b1을 읽고 공백으로 바꿈. b1==0이면 r0read2nd로 이동. b1==1이면 b2는 무조건 0. 주먹, 가위로 주먹 승리. rdelete로 이동.
state s에서 일단 공백을 읽고 무시. b1을 읽고 공백으로 바꿈. b1==0이면 s0read2nd로 이동. b1==1이면 b2는 무조건 0. 가위, 가위로 무승부. sdelete로 이동.
state p에서 일단 공백을 읽고 무시. b1을 읽고 공백으로 바꿈. b1==0이면 b1b2는 주먹이나 보, 따라서 무조건 보 출력. pdelete로 이동. b1==1이면 b2는 무조건 0. 보, 가위로 가위가 승리. sdelete로 이동.
state r0read2nd에서 b2를 읽고 공백으로 바꿈. b2==0이면 주먹, 주먹으로 무승부. rdelete로 이동. b2==1이면 주먹, 보로 보 승리. pdelete로 이동.
state s0read2nd에서 b2를 읽고 공백으로 바꿈. b2==0이면 가위, 주먹으로 주먹 승리. rdelete로 이동. b2==1이면 가위, 보로 가위 승리. sdelete로 이동.
state rdelete에서 공백을 읽으면 유지하고 pr0로 이동. 0이나 1을 읽으면 공백으로 바꾸고 rdelete 유지.
state sdelete에서 공백을 읽으면 유지하고 ps1로 이동. 0이나 1을 읽으면 공백으로 바꾸고 sdelete 유지.
state pdelete에서 공백을 읽으면 유지하고 pp0로 이동. 0이나 1을 읽으면 공백으로 바꾸고 pdelete 유지.
state pr0에서 0을 출력하고 pr00로 이동.
state ps1에서 1을 출력하고 ps10로 이동.
state pp0에서 0을 출력하고 pp01로 이동.
state pr00에서 0을 출력하고 halt.
state ps10에서 0을 출력하고 halt.
state pp01에서 1을 출력하고 halt.
//2A

state 간 이동은 {.,+,-}기호를 이용. 현재 상태를 "!"로 표시, 각 상태를 ":"로 구분. 입력에 따른 행동을 ","로 구분.
state 별 기능:
q1 = 3n번째 1을 입력받은 상태
q2 = 3n+1번째 1을 입력받은 상태
q3 =3n+2번째 1을 입력받은 상태
q4 = accept 상태
q5 = reject 상태
q6 = halt
//2B
state sequence: q1, q2, q3, q4, q5
state 간 이동은 {.,+,-}기호를 이용. 현재 상태를 "!"로 표시, 각 상태를 ":"로 구분. 입력에 따른 행동을 ","로 구분.
state 별 기능:
q1 = 짝수번 째 자리를 읽는 상태
q2 = 홀수번 째 자리를 읽는 상태
q3 = accept 상태
q4 = reject 상태
q5 = halt
//2C
state sequence: q1, q2, q3, q4, q5, q6, q7, q8, q9, q10
state 간 이동은 {.,+,-}기호를 이용. 현재 상태를 "!"로 표시, 각 상태를 ":"로 구분. 입력에 따른 행동을 ","로 구분.
state 별 기능:
q1 = 4n+1번 째 자리를 읽는 상태
q2 = 4n+2번 째 자리, 1이 짝수개인 상태
q3 = 4n+2번 째 자리, 1이 홀수개인 상태
q4 = 4n+3번 째 자리, 1이 짝수개인 상태
q5 = 4n+3번 째 자리, 1이 홀수개인 상태
q6 = 4n번 째 자리, 1이 짝수개인 상태
q7 = 4n번 째 자리, 1이 홀수개인 상태
q8 = accept 상태
q9 = reject 상태
q10 = halt
//2D
state sequence: q1, q2, q3
state 간 이동은 {.,+,-}기호를 이용. 현재 상태를 "!"로 표시, 각 상태를 ":"로 구분. 입력에 따른 행동을 ","로 구분.
state 별 기능:
q1 = 입력의 첫자리부터 첫 0이 나올 때까지 머무는 상태
q2 = 첫 0이 나왔을 때부터 보수를 출력하는 상태
q3 = halt
q1이나 q2에서 공백을 만나면 바로 halt하도록 함.
//2E
state sequence: q1, q2, q3, q4, q5, q6
state 간 이동은 {.,+,-}기호를 이용. 현재 상태를 "!"로 표시, 각 상태를 ":"로 구분. 입력에 따른 행동을 ","로 구분.
설명의 편의를 위해 input의 형식을 다음과 같이 정의: "a1a2_b1b2" (올바른 형태의 input만 들어옴)
state 별 기능:
q1 = a1을 읽는 상태
q2 = a1이 0일 때 a2를 읽는 상태
q3 = a1이 1일 때 a2를 읽는 상태
q4 = a1a2가 주먹인 상태.
q5 = a1a2가 가위인 상태.
q6 = a1a2가 보인 상태.
q7 = a1a2가 주먹이고 b1이 0인 상태.
q8 = a1a2가 주먹이고 b1이 0인 상태.
q9 = 주먹이 이겼고 남은 입력을 지우는 상태.
q10 = 가위가 이겼고 남은 입력을 지우는 상태.
q11 = 보가 이겼고 남은 입력을 지우는 상태.
q12 = 주먹(00) 중 앞 0을 출력하는 단계
q13 = 가위(10) 중 1을 출력하는 단계
q14 = 보(01) 중 0을 출력하는 단계
q15 = 주먹(00) 중 뒤 0을 출력하는 단계
q16 = 가위(10) 중 0을 출력하는 단계
q17 = 보(01) 중 1을 출력하는 단계
q18 = halt
