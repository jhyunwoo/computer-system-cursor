# TF32 Edge Case Verification Test Suite

## 개요

`test_debug.c`는 TF32 구현의 다양한 엣지 케이스와 경계 조건을 검증하는 포괄적인 테스트 스위트입니다.

## 빌드 및 실행

```bash
# 컴파일
gcc -o test_debug test_debug.c tf32.c

# 실행
./test_debug

# 특정 섹션만 보기
./test_debug | grep -A 20 "tf32_add"
```

## 테스트 카테고리

### 1. int2tf32 - 정수를 TF32로 변환
- ✅ Zero (0)
- ✅ 양수 정수 (1, 37, 3001)
- ✅ 음수 정수 (-1, -13)
- ✅ 경계값 (INT_MIN, INT_MAX)
- ✅ 2의 거듭제곱

**검증 항목:**
- 정확한 비트 패턴 생성
- Round-to-even 반올림
- 부호 처리

### 2. tf322int - TF32를 정수로 변환
- ✅ Zero (±0)
- ✅ 양수/음수 정수
- ✅ 특수값 (Inf → INT_MAX/MIN, NaN → INT_MIN)
- ✅ 비정규화 수 → 0

**검증 항목:**
- 오버플로우/언더플로우 처리
- 특수값 변환 규칙
- 부호 보존

### 3. double2tf32 - Double을 TF32로 변환
- ✅ Zero (±0.0)
- ✅ 일반 숫자 (1.0, -2025.5)
- ✅ 특수값 (±Inf, NaN)
- ✅ 매우 큰 수 (오버플로우 → Inf)
- ✅ 매우 작은 수 (언더플로우 → 0)

**검증 항목:**
- IEEE 754 호환성
- 오버플로우/언더플로우
- NaN 표현 (0x3FE00)

### 4. tf322double - TF32를 Double로 변환
- ✅ Zero, 일반 숫자, 특수값
- ✅ 비정규화 수 처리

**검증 항목:**
- 정확한 값 복원
- 비정규화 수 특수 규칙 (2^-126 매핑)

### 5. tf32_add - TF32 덧셈
- ✅ 기본 덧셈 (1+1=2)
- ✅ Zero 처리 (x+0=x)
- ✅ 부호 조합 (1+(-1)=0)
- ✅ 무한대 (Inf+x, Inf-Inf)
- ✅ 비정규화 수 덧셈

**검증 항목:**
- 지수 정렬
- 가수 덧셈/뺄셈
- 정규화
- 오버플로우

### 6. tf32_mul - TF32 곱셈
- ✅ 기본 곱셈 (2*2=4)
- ✅ Zero (0*x=0)
- ✅ 부호 규칙 ((-1)*(-1)=1)
- ✅ 무한대 (Inf*x, Inf*0)
- ✅ 언더플로우 (denorm*denorm→0)

**검증 항목:**
- 가수 곱셈 (11비트 × 11비트)
- 지수 계산
- 정규화
- Round-to-even

### 7. tf32_div - TF32 나눗셈 (Newton-Raphson)
- ✅ 기본 나눗셈 (4/2=2)
- ✅ 0으로 나누기 (x/0=Inf, 0/0=NaN)
- ✅ 무한대 (Inf/Inf, x/Inf)
- ✅ Newton-Raphson 정확도
- ✅ 부호 조합

**검증 항목:**
- Newton-Raphson 5회 반복
- 역수 계산 정확도 (±0.1 이내)
- 특수값 처리

### 8. tf32_compare - TF32 비교
- ✅ 동등 (==, ±0 동등성)
- ✅ 대소 비교 (<, >)
- ✅ NaN 비교 (항상 -2)
- ✅ 무한대 비교
- ✅ 음수 비교

**검증 항목:**
- 비교 논리
- NaN 처리
- 부호 고려

### 9. Edge Cases & Stress Tests
- ✅ Round-to-even 검증
- ✅ 비정규화 수 처리
- ✅ 오버플로우 시나리오
- ✅ 정밀도 한계
- ✅ 비트 패턴 검증

**검증 항목:**
- 극한 상황 안정성
- 비트 패턴 정확성

### 10. Consistency & Roundtrip Tests
- ✅ int → tf32 → int 왕복 변환
- ✅ 산술 항등식 (x+0=x, x*1=x, x/1=x)

**검증 항목:**
- 변환 일관성
- 항등식 보존

## 테스트 결과 해석

### PASS 표시
```
✓ PASS: 1.0 + 1.0 = 2.0 (0x20000)
```
- 테스트가 예상 결과와 일치

### FAIL 표시
```
✗ FAIL: 2 + (-4) = -2
  Expected: 0x5fc00
  Got:      0x60000
```
- 예상 값과 실제 값이 다름
- 구현 검토 필요 또는 예상 값 조정 필요

## 주요 검증 항목

### ✅ IEEE 754 호환성
- 특수값 (±0, ±Inf, NaN)
- 비정규화 수
- Round-to-even 반올림

### ✅ 경계 조건
- INT_MIN/MAX
- 오버플로우/언더플로우
- 최소/최대 표현 가능 값

### ✅ 산술 정확도
- Newton-Raphson 수렴
- 정밀도 손실 최소화
- 특수 케이스 처리

### ✅ 일관성
- 왕복 변환 검증
- 항등식 보존
- 부호 일관성
