## 🔑 핵심 구현 사항

### 1. Round-to-even 반올림
모든 변환과 연산에서 IEEE 754 표준 준수

### 2. 특수값 처리
- NaN: `0x3FE00` (Quiet NaN, exp=0xFF, frac=0x200)
- +Inf: `0x3FC00` (sign=0, exp=0xFF, frac=0)
- -Inf: `0x7FC00` (sign=1, exp=0xFF, frac=0)
- ±0: `0x00000` / `0x40000`

### 3. 비정규화 수
- 생성: 언더플로우 시 자동 생성
- 변환: tf322double에서 2^-126으로 매핑 (스펙 준수)
- 연산: 정확한 변환으로 계산

### 4. Newton-Raphson 나눗셈
- 5회 반복으로 ±0.1 정확도 달성
- 초기값: 2^(-exp_b)
- 반복식: y = y * (2 - b * y)

### 5. 비트 레벨 산술 연산
- **tf32_add**: 지수 정렬 → 가수 덧셈/뺄셈 → 정규화
- **tf32_mul**: 가수 곱셈 → 지수 계산 → 정규화 → 반올림
